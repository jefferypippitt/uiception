title: Introduction
description: What uiception is and how it's built.
order: 1
---

uiception is a shadcn-compatible block registry. Browse sections on the site, install any
block with the CLI, and customize from there — start from complete sections instead of
empty components.

It's built with Next.js 16 (App Router, Turbopack), React 19, shadcn/ui, and Tailwind CSS
v4, with GSAP and Motion for animation. The registry itself follows the shadcn CLI format:
`registry.json` builds out to `public/r/*.json`.
