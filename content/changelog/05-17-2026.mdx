A larger drop built around mockups and first FAQ, with dock and mono navbar options and an authentication brands strip.

- **Brands Section v6.** Security trust strip of auth brand logos including Clerk, Better Auth, Auth0, and more.
- **FAQ Section v1.** Centered minimal FAQ with a clean divider accordion.
- **Navbar Section v5.** Sticky top dock that shrinks on scroll, with a frosted pill and two column desktop layout.
- **Navbar Section v6.** Centered mono uppercase nav with a Solutions dropdown and external Docs link.
- **Google Chrome (macOS).** Tab strip, omnibox, bookmarks bar, and a light and dark new tab preview.
- **Google Chrome (Windows).** Win32 title bar tabs and native window controls.
- **Spreadsheet.** Sheets style subscription grid with trial upgrades and Stripe webhook row sync.
